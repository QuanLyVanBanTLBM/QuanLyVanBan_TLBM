# Thư mục Tài liệu Cục bộ (Local Documents Directory)

Thư mục này được sử dụng cho tính năng **"Đồng bộ Thư mục Local (Máy tính)"** trong phân hệ **Kho Tài Liệu & Biểu Mẫu**.
Khi quản trị viên thực hiện đồng bộ tài liệu mà không nhập đường dẫn cụ thể, hệ thống sẽ tự động quét và lập chỉ mục cây thư mục mặc định `./Folder` này.

## Cấu trúc thư mục mẫu:
- `folder1/`:
  - `item1.docx`
  - `item2.docx`
  - `item3.docx`
- `folder2/`:
  - `item1.docx`
  - `item2.docx`
  - `item3.docx`
